# Servidor Eternal

O servidor deve usar o mesmo `pack.toml` e `index.toml` da release do cliente. Instale o NeoForge 21.1.250 com Minecraft 1.21.1 e aplique o pack em uma pasta separada da instância do cliente.

Antes de criar o mundo persistente:

1. Inicie uma instalação limpa.
2. Aceite o EULA somente no servidor que será usado.
3. Verifique o log de carregamento dos mods e do KubeJS.
4. Conecte com um cliente limpo da mesma release.
5. Faça o primeiro backup antes de iniciar a progressão real.

Não copie configurações client-only, mapas Xaero ou Controlify para o servidor. Mantenha backups versionados por data e nunca atualize mods automaticamente em um mundo ativo.
